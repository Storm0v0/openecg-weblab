# GitHub 静态项目发布准备

`01_离线演示/prepare_github.py` 仅使用 Python 标准库，按精确白名单生成一个可审查的仓库目录与 ZIP，不创建远程仓库、不执行 Git、不上传、不连接云服务器。

仓库根 README 面向使用者提供在线演示入口、功能、克隆地址、本机查看与构建命令、算法口径、来源许可和局限。当前 GitHub 仓库为私有，查看或克隆源码需获得访问权限；在线静态演示独立提供访问。

在交接根目录完成静态发布验收后执行：

```sh
python "01_离线演示/release_static.py"
python "01_离线演示/prepare_github.py" --check
python "01_离线演示/prepare_github.py"
```

默认输出为根目录下 `06_GitHub发布准备/openecg-weblab/` 和同级 `openecg-weblab.zip`。首次生成后可以将该目录作为 GitHub 仓库的工作目录。若要在不影响原目录的情况下复核，可把 ZIP 解压到另一个临时目录，再运行其中的 `01_离线演示/release_static.py`；该检查覆盖冻结输出的分析和网页，不调用模型。

## 纳入范围

- 离线网页模板、交互脚本、样式、单文件 HTML、构建、模拟 DOM 检查、发布与本准备脚本。
- QRS 测量及人工区间对照模块、其测试，以及可选的原始 ECG 模型生成脚本和测试。
- 二十条演示 JSON、二十份分析 JSON、三份分析 CSV；统一目录为 `scripts/demo_catalog.py`，LUDB 与 QTDB 各十条。
- LUDB 与 QTDB 共六十个 WFDB 原始文件、官方来源校验清单。
- 通用静态部署的首页、HTTP 服务、安装脚本、HTTP 检查及重新撰写的脱敏部署说明。
- 精简中文 README、定量对照协议、来源与许可说明、依赖列表和校验清单。
- 如存在则附带 `03_网站与算法源码/public/generation_manifest.json`；本次新增模式只生成六条、保留此前十四条，不将本次模型运行认领到保留记录。目录已完整时再次运行只校验，不覆盖真实推理清单。
- 此前十四条的生成清单按原字节保留在 `public/generation_history/generation_14_records_20261018.json`；原四条模型复现核查另存 `public/model_replay_audit.json`。
- 提供 `public/preservation_14_records_manifest.json`，只含项目内相对路径、大小和 SHA-256，保护已有十四条预测、十四份分析及四十二个源文件，不复制原交接目录。

`requirements-inference.txt` 仅从历史依赖文件中筛出 `openecg[deploy]==0.11.0`、`wfdb==4.3.1`、`scipy==1.17.1`、`numpy==1.26.4` 四项。模型运行环境及实际包版本以 `public/generation_manifest.json` 和 `public/model_replay_audit.json` 为准；权重不随包分发。静态分析和构建不需要这四项依赖。

## 排除范围

不复制 FastAPI 后端、React/Sites 模板、vendor、平台配置、历史截图、交接文档、SSH 凭据、内部用户路径、内部云主机配置、私钥或 `.env`。根 README 保留用户授权的完整在线演示 URL；通用部署说明继续使用地址占位符，私有部署回执不纳入仓库。

生成包记录 OpenECG 官方 Apache-2.0 项目来源以及 LUDB/QTDB 的 ODC Attribution License v1.0，保留作者、数据版本、DOI、许可证 URI 及派生变换说明。各数据、模型和第三方软件继续适用各自条款；生成器不为它们统一换许可证，也没有替作者选择课程新增代码的授权许可证。

这些演示示例及其冻结模型输出不构成独立泛化测试。无完整人工区间的类别不可评价；未标注区域不计误检。没有模型重新推理、真实浏览器、公网验收记录时，不宣称已完成这些验证。

页面打开自动展示 LUDB 16，点击数据库或选择记录后自动展示；不会触发模型在线计算。局部缩放、定位和筛选只改变查看范围，统计和 CSV 导出仍基于完整十秒记录。静态服务默认使用 HTTP 80 端口，访问无需端口后缀；8080 可按部署说明选择。

## 重复运行和校验

生成器在目标目录保存 `.openecg-package-state.json`，只更新该标记记录的自有文件。发现同名无标记目录、非自有文件冲突、手工修改过的受管理文件或 ZIP 时停止；不会递归删除目录、清除用户新增文件或静默覆盖手工改动。过往受管理但本轮不在白名单的文件保留在目录内，不进入本轮 ZIP。

文件和 ZIP 均以临时文件完整写入后原子替换。ZIP 只从当次白名单构建，使用固定时间戳，验证无多余/重复路径且逐文件 SHA-256 一致。`release-manifest.json` 列出除它自身以外的全部打包文件；`SHA256SUMS` 列出除两个校验清单自身外的内容文件。标记仅用于本地生成器管理，不进入 ZIP。

生成器执行有限的文本检查，发现本地用户路径、数字形式的非本机 IPv4 地址或私钥头会停止。唯一网址例外仅限根 README 和生成器源码内用户授权的完整演示 URL；先移除该完整 URL 后，仍执行原有检查，不豁免其他 IP、附加端口、子路径、用户路径或私钥。它不能替代通用秘密扫描；避免泄漏的主要措施是精确白名单与脱敏说明。

公网 HTTP 服务、首页内容和使用者确认可见的初始页面可以如实说明；自动浏览器在当前客户端受限，不能据此宣称全套真实浏览器交互或下载验收。包完整性、算法测试、浏览器和公网验证分别判断。
